data-rq-attr-*

Set any HTML attribute from state. Replace * with the attribute name you want to control — href, src, disabled, placeholder, anything else.

<a data-rq-attr-href="key">…</a>
<img data-rq-attr-src="key" />
<input data-rq-attr-placeholder="key" />
<button data-rq-attr-disabled="key">…</button>

How it works

State value Result on the element
A string or number Sets the attribute to that value (e.g. href="/page/3")
true Sets the attribute with no value (e.g. disabled on a button)
false or null Removes the attribute entirely
1

Enable or disable a button

html 
<div id="app">
  <label>
    <input type="checkbox" id="agree" />
    I agree to the terms
  </label>
  <br /><br />
  <button data-rq-attr-disabled="btnDisabled">
    Submit
  </button>
</div>
js 
$('#app').rqState({ btnDisabled: true });

$('#agree').on('change', function () {
  // unchecked → button disabled; checked → button enabled
  $('#app').rqSet('btnDisabled', !this.checked);
});
Live demo — check the box to enable the button

Dynamic link URL

html 
<div id="app">
  <select id="picker">
    <option value="https://jquery.com">jQuery</option>
    <option value="https://vitejs.dev">Vite</option>
    <option value="https://vitest.dev">Vitest</option>
  </select>
  <a data-rq-attr-href="url" target="_blank">
    Visit site →
  </a>
</div>
js 
$('#app').rqState({ url: 'https://jquery.com' });

$('#picker').on('change', function () {
  $('#app').rqSet('url', this.value);
});
