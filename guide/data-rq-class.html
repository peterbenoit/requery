data-rq-class-*

Toggle a CSS class based on a state value. Replace * with the class name — the class is added when the state value is truthy and removed when it's falsy.

<div data-rq-class-active="isActive">…</div>
<input data-rq-class-error="hasError" />
<button data-rq-class-loading="isLoading">…</button>

How it works

State value Effect on the class
truthy (true, non-zero, non-empty string) Class is added
falsy (false, 0, null, '') Class is removed
1

Highlight a card on toggle

html 
<div id="app">
  <div class="card" data-rq-class-highlighted="on">
    This card can be highlighted.
  </div>
  <button id="toggle">Toggle highlight</button>
</div>

<style>
  .card { padding: 1rem; border: 2px solid #e2e8f0; border-radius: 8px; }
  .card.highlighted { border-color: #6366f1; background: #eef2ff; }
</style>
js 
$('#app').rqState({ on: false });

$('#toggle').on('click', function () {
  $('#app').rqMutate('on', function (val) { return !val; });
});

Validation error on an input

html 
<div id="app">
  <input
    id="email"
    type="email"
    placeholder="Enter email"
    data-rq-class-input-error="hasError"
  />
  <p data-rq-show="hasError" class="error-msg">
    Please enter a valid email.
  </p>
</div>

<style>
  .input-error { border-color: #ef4444 !important; }
  .error-msg { color: #ef4444; font-size: 0.8rem; margin-top: 0.25rem; }
</style>
js 
$('#app').rqState({ hasError: false });

$('#email').on('blur', function () {
  var ok = this.value.includes('@');
  $('#app').rqSet('hasError', !ok);
});
