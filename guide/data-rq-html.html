data-rq-html

Sets the inner HTML of an element. Unlike data-rq-text, this renders the value as actual HTML — so you can include tags like <strong>, <a>, and so on.

<div data-rq-html="key"></div>

Usage

Attribute value What it does
a state key name Sets innerHTML of the element to the value of that key. HTML tags in the value are rendered, not escaped.
1

Swap rich HTML content

html 
<div id="app">
  <div data-rq-html="content"></div>
  <button id="toggle">Switch content</button>
</div>
js 
var contentA = '<p><strong>Panel A</strong> — first view</p>';
var contentB = '<p><em>Panel B</em> — <a href="#">with a link</a></p>';

$('#app').rqState({ content: contentA });

$('#toggle').on('click', function () {
  $('#app').rqMutate('content', function (cur) {
    return cur === contentA ? contentB : contentA;
  });
});
Live demo
2

Markdown-style bold/italic preview

js 
$('#app').rqState({ raw: 'Hello **world**!' });

// A simple computed that converts **bold** to <strong>
$('#app').rqComputed('preview', function (state) {
  return state.raw.replace(/\*\*(.+?)\*\*/g, '<strong>$1</strong>');
});
Live demo — type with **double stars** for bold
PREVIEW
Security note: Only use data-rq-html with content you trust. If the value comes from user input or an external source, make sure to sanitize it first — otherwise you could accidentally introduce XSS vulnerabilities. For user-facing text, data-rq-text is the safer choice.
