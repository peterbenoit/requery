data-rq-on-*

Wire events straight from HTML without writing jQuery selectors. Add data-rq-on-click="myAction" to any element, define myAction in the actions option, and reQuery handles the wiring for you.

<button data-rq-on-click="increment">+</button>
<input data-rq-on-input="onType" />
<form data-rq-on-submit="onSubmit">…</form>

Action function signature

Argument What it is
state The current state object (read-only snapshot)
event The native jQuery event object
$root The jQuery-wrapped root element (the one you called .rqState() on)
Return a plain object with the state keys you want to update, or nothing (undefined) to leave state unchanged.
1

Counter with named actions

html 
<div id="app">
  <button data-rq-on-click="decrement">−</button>
  <span data-rq-text="count"></span>
  <button data-rq-on-click="increment">+</button>
  <button data-rq-on-click="reset">Reset</button>
</div>
js 
$('#app').rqState({ count: 0 }, {
  actions: {
    increment: function (state) {
      return { count: state.count + 1 };
    },
    decrement: function (state) {
      return { count: state.count - 1 };
    },
    reset: function () {
      return { count: 0 };
    }
  }
});
Live demo — all wiring is in the HTML attributes

Form submit action

html 
<div id="app">
  <form data-rq-on-submit="save">
    <input type="text" data-rq-val="name" placeholder="Your name" />
    <button type="submit">Save</button>
  </form>
  <p data-rq-show="saved">
    Saved! Hello, <strong data-rq-text="name"></strong>.
  </p>
</div>
js 
$('#app').rqState({ name: '', saved: false }, {
  actions: {
    save: function (state, event) {
      event.preventDefault();
      if (!state.name.trim()) return;
      return { saved: true };
    }
  }
});
