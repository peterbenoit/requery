data-rq-show

Show or hide an element based on a state value. When the value is truthy the element is shown; when falsy it's hidden. Works exactly like jQuery's .show() and .hide() — no CSS class tricks needed.

<div data-rq-show="key">…</div>

How it works

State value Element visibility
truthy (true, non-zero, non-empty string) Element is shown
falsy (false, 0, null, '') Element is hidden (display:none)
1

Show / hide a panel

html 
<div id="app">
  <button id="toggle">Show details</button>

  <div data-rq-show="open" class="panel">
    Here are the hidden details.
    They appear when you click the button.
  </div>
</div>
js 
$('#app').rqState({ open: false });

$('#toggle').on('click', function () {
  $('#app').rqMutate('open', function (val) {
    $(this).text(val ? 'Show details' : 'Hide details');
    return !val;
  });
});

2

Conditional success message

html 
<div id="app">
  <input id="code" type="text" placeholder="Enter code" />
  <button id="submit">Submit</button>

  <p data-rq-show="correct" class="success">
    ✓ Correct! Welcome aboard.
  </p>
  <p data-rq-show="wrong" class="error">
    ✗ Wrong code. Try again.
  </p>
</div>
js 
$('#app').rqState({ correct: false, wrong: false });

$('#submit').on('click', function () {
  var val = $('#code').val().trim();
  $('#app').rqSet({ correct: val === 'open', wrong: val !== 'open' });
});
Live demo — type open and click Submit
