data-rq-text

Displays a state value as the text content of an element. This is the most common binding — use it anywhere you want a number, name, or message to update automatically.

<span data-rq-text="key"></span>

Usage

Attribute value What it shows
a state key name The current value of that key, as plain text. HTML tags in the value are escaped automatically.
1

Show a counter

html 
<div id="app">
  <p>Count: <span data-rq-text="count"></span></p>
  <button id="inc">+1</button>
</div>
js 
$('#app').rqState({ count: 0 });

$('#inc').on('click', function () {
  $('#app').rqMutate('count', function (n) { return n + 1; });
});

2

Live greeting as you type

html 
<div id="app">
  <input type="text" data-rq-val="name" placeholder="Your name" />
  <p>Hello, <strong data-rq-text="name"></strong>!</p>
</div>
js 
$('#app').rqState({ name: 'World' });
Live demo — type your name

Hello, !

Plain text only. If your value contains HTML tags, they will be displayed as text, not rendered as HTML. Use data-rq-html if you need to render markup.
