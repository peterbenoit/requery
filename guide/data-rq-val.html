data-rq-val

Two-way binding for form fields. The input's value reflects the state, and whenever the user types or picks something, the state updates too — automatically, no event handler needed.

<input data-rq-val="key" />
<textarea data-rq-val="key"></textarea>
<select data-rq-val="key">…</select>

Usage

Attribute value Behavior
a state key name The input is initialized with the state value. Any time the user changes the input, that state key updates. Any time .rqSet() changes the state key, the input updates.
1

Live character count

html 
<div id="app">
  <textarea data-rq-val="bio" placeholder="Write a bio…"></textarea>
  <p><span data-rq-text="charCount"></span> characters</p>
</div>
js 
$('#app')
  .rqState({ bio: '' })
  .rqComputed('charCount', function (state) {
    return state.bio.length;
  });

Multiple inputs sharing state

html 
<div id="app">
  <input type="text"  data-rq-val="color" />
  <input type="color" data-rq-val="color" />
  <div id="swatch"></div>
</div>
js 
$('#app').rqState({ color: '#6366f1' });

$('#app').rqWatch('color', function (val) {
  $('#swatch').css('background', val);
});
Live demo — pick a color or type a hex code
