Examples for every method and attribute. If you know jQuery, you already know most of this.

The idea in one sentence

You tell reQuery what your data looks like, put data-rq-text (or similar) attributes on the HTML elements that should show it, and from then on calling .rqSet() updates the page automatically — no manual DOM hunting required.

▶

A 9-line counter

html 
<div id="counter">
  <p>Count: <span data-rq-text="count"></span></p>
  <button id="inc">+1</button>
</div>
js 
$('#counter').rqState({ count: 0 });

$('#inc').on('click', function () {
  $('#counter').rqMutate('count', function (n) { return n + 1; });
});

Plugin Methods

.rqState()
Set up your data on an element
.rqGet()
Read the current value of a key
.rqSet()
Change a value and update the page
.rqMutate()
Update a value based on what it already is
.rqWatch()
Run code whenever a value changes
.rqComputed()
Derive a value from other values
.rqReset()
Go back to the original values
.rqDestroy()
Remove all state from an element

HTML Attributes

Add these attributes to any HTML element inside your root element. reQuery updates them automatically when the matching state key changes.

data-rq-text
Set the text content of an element
data-rq-html
Set the HTML content of an element
data-rq-val
Two-way bind an input field
data-rq-attr-*
Set any HTML attribute dynamically
data-rq-class-*
Toggle a CSS class on or off
data-rq-show
Show or hide an element
data-rq-each
Repeat a template for every item in a list
data-rq-on-*
Wire up events without writing handlers
