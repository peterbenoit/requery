Saving Data

Pass persist: 'my-key' when you call .rqState() and reQuery will automatically save state to localStorage on every change — and reload it when the page loads. The user's data survives a refresh without you writing a single line of storage code.

$('#app').rqState({ … }, { persist: 'my-storage-key' });

Options

Option Type What it does
persist string The localStorage key to use. Pick any unique string — something descriptive like 'my-counter' or 'user-prefs'. State is saved as JSON automatically on every .rqSet() call. On page load the saved data is merged on top of your defaults.
1

Counter that survives a page reload

html 
<div id="app">
  <button id="dec">−</button>
  <span data-rq-text="count"></span>
  <button id="inc">+</button>
  <button id="clear">Clear saved data</button>
</div>
js 
$('#app').rqState({ count: 0 }, { persist: 'my-counter' });

$('#inc').on('click', function () {
  $('#app').rqMutate('count', function (n) { return n + 1; });
});
$('#dec').on('click', function () {
  $('#app').rqMutate('count', function (n) { return n - 1; });
});
$('#clear').on('click', function () {
  localStorage.removeItem('my-counter');
  $('#app').rqReset();
});

2

User preferences form

html 
<div id="prefs">
  <label>Display name</label>
  <input type="text" data-rq-val="name" />

  <label>Theme</label>
  <select data-rq-val="theme">
    <option value="light">Light</option>
    <option value="dark">Dark</option>
  </select>

  <p>Hello, <span data-rq-text="name"></span>! Theme: <span data-rq-text="theme"></span></p>
</div>
js 
// Defaults are used only on the first visit.
// After that, whatever the user typed is restored automatically.
$('#prefs').rqState(
  { name: 'Friend', theme: 'light' },
  { persist: 'user-prefs' }
);
