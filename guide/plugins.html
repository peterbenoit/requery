Building Plugins

reQuery is designed to stay small. The plugin system is how you add new capabilities without modifying core — you get controlled access to reQuery's internals and can register your own $.fn.rq* methods just like the built-in ones.

How it works

Call $.reQuery.use(fn) with a function. That function runs immediately and receives a context object with everything it needs to read state, write state, and add new jQuery methods. That's the entire API.

$.reQuery.use( pluginFn )

The context object

Property Type Description
$ jQuery The jQuery instance reQuery is registered on. Use this to add $.fn methods.
getRecord(el) function Returns the internal state record for a DOM element, or null if it has no state. The record has data, initial, watchers, and computed properties.
setState(el, key, value) function Write a state value and trigger DOM updates — same as calling .rqSet() but works directly on a DOM element without a jQuery wrapper.
mutateState(el, key, fn) function Update state via a callback — same as .rqMutate() but element-direct.
addWatcher(el, key, fn) function Register a watcher for a key — same as .rqWatch() but element-direct.
addComputed(el, key, fn) function Register a computed value — same as .rqComputed() but element-direct.
1

The simplest possible plugin

A plugin that adds .rqLog() — prints the current state to the console.

js 
$.reQuery.use(function ({ $, getRecord }) {
  $.fn.rqLog = function () {
    return this.each(function () {
      var rec = getRecord(this);
      if (rec) console.log('[reQuery state]', rec.data);
    });
  };
});

// Then use it like any other reQuery method:
$('#app').rqState({ count: 0, name: 'hello' });
$('#app').rqLog();
// → [reQuery state] { count: 0, name: 'hello' }

Reading and writing state from a plugin

Use getRecord to read, setState to write (DOM updates included).

js 
$.reQuery.use(function ({ $, getRecord, setState }) {

  // Reset a single key to its initial value
  $.fn.rqRevertKey = function (key) {
    return this.each(function () {
      var rec = getRecord(this);
      if (rec && key in rec.initial) {
        setState(this, key, rec.initial[key]);
      }
    });
  };

});

$('#app').rqState({ score: 100 });
$('#app').rqSet('score', 999);
$('#app').rqRevertKey('score');
// score is 100 again

Watching state changes in a plugin

Use addWatcher to react to state changes — great for side effects like analytics, logging, or syncing to an external service.

js 
$.reQuery.use(function ({ $, addWatcher }) {

  // Track every change to a specific key and keep a history
  $.fn.rqHistory = function (key, limit) {
    limit = limit || 10;
    return this.each(function () {
      var el = this;
      var history = [];
      $(el).data('rq-history-' + key, history);

      addWatcher(el, key, function (newVal) {
        history.unshift(newVal);
        if (history.length > limit) history.pop();
      });
    });
  };

  $.fn.rqGetHistory = function (key) {
    return $(this[0]).data('rq-history-' + key) || [];
  };

});

$('#app').rqState({ count: 0 }).rqHistory('count', 5);
// After a few rqSet calls:
// $('#app').rqGetHistory('count') → [3, 2, 1, 0] (most recent first)

Rules for well-behaved plugins

  • Prefix your method names. Use something distinctive so you don't accidentally collide with core reQuery methods or other plugins. rqValidate, rqUndo, rqSync — pick a clear prefix and stick to it.
  • Always check for a state record. Call getRecord(el) first and bail out (with an optional console.warn) if it returns null. Your method may be called on an element that doesn't have rqState yet.
  • Return this unless you're returning a value. All $.fn methods should return this to keep jQuery chains working, unless the point of the method is to return a specific value (like a boolean or string).
  • Use setState, not direct writes to record.data. The context's setState triggers DOM updates, watchers, and onChange. Writing to record.data directly skips all of that.
  • Namespace your jQuery events. If your plugin adds event listeners, use .on('click.myplugin', ...) so they can be cleaned up cleanly.
