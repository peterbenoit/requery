.rqComputed()

Create a value that is automatically calculated from other state values. Instead of storing it separately and remembering to update it, you just describe how to calculate it — reQuery keeps it current.

$(selector).rqComputed( key, function(state) { return derivedValue; } )

Parameters

Name Type Required Description
key string yes The name for this computed value. Use it in data-rq-text etc. just like a regular state key.
fn function yes Receives the full state object. Return the computed value you want to show.
Returns: the jQuery object (chainable)
1

Full name from first + last

js 
$('#app')
  .rqState({ first: 'Ada', last: 'Lovelace' })
  .rqComputed('fullName', function (state) {
    return state.first + ' ' + state.last;
  });

2

Total price from quantity × price

js 
$('#app')
  .rqState({ qty: 1, price: 9.99 })
  .rqComputed('total', function (state) {
    return '$' + (state.qty * state.price).toFixed(2);
  });

How it works: Every time any state key changes, reQuery re-runs your computed function and updates the DOM if the result is different. You don't need to do anything — just use the computed key name in your HTML like any other key.
