.rqDestroy()

Remove all reactive state from an element and disconnect all its event listeners. After this, the element is just plain HTML again — as if .rqState() was never called.

$(selector).rqDestroy()

Parameters

None. This method takes no arguments.

Returns: the jQuery object (chainable)
1

Destroy and reinitialize

js 
$('#app').rqState({ count: 0 });

$('#destroy-btn').on('click', function () {
  $('#app').rqDestroy();
  // The element still exists, but reQuery is gone
  // You can call .rqState() again to start fresh
});

$('#reinit-btn').on('click', function () {
  $('#app').rqState({ count: 0 });
});
Live demo — destroy removes reactivity; reinit brings it back
Count:

When would you use this? Mostly in single-page apps where you load and unload sections of the page dynamically. If a widget is removed from the DOM, calling .rqDestroy() first ensures any watchers and handlers are properly cleaned up.
