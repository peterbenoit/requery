.rqGet()

Read the current value of a state key. Use this any time you need to know what a value is before doing something with it — like adding 1 to a counter.

$(selector).rqGet( key ) → value
$(selector).rqGet() → { all keys and values }

Parameters

Name Type Required Description
key string optional The state key to read. If you leave this out, you get back an object with every key and its current value.
Returns: the current value of that key, or a snapshot object of all state if called with no argument.
Note: unlike most reQuery methods, this one does NOT return the jQuery object — it returns the value.
1

Read a single key

js 
$('#app').rqState({ count: 5 });

// Read the current value of 'count'
var current = $('#app').rqGet('count');
console.log(current); // 5

// A common pattern: read, add 1, write back
$('#inc').on('click', function () {
  var n = $('#app').rqGet('count');
  $('#app').rqSet('count', n + 1);
});

2

Read everything at once (no-argument form)

js 
$('#app').rqState({ name: 'Ada', score: 99, active: true });

// No argument: get a snapshot of the whole state
var snapshot = $('#app').rqGet();
console.log(snapshot);
// { name: 'Ada', score: 99, active: true }
