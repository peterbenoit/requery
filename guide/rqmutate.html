.rqMutate()

Update a state value based on what it currently is. You give it a function that receives the old value and returns the new one — perfect for counters, toggles, and arrays.

$(selector).rqMutate( key, function(currentValue) { return newValue; } )

Parameters

Name Type Required Description
key string yes The state key to update.
fn function yes Called with the current value. Whatever you return becomes the new value.
Returns: the jQuery object (chainable)
1

Increment and decrement a counter

js 
$('#app').rqState({ count: 0 });

$('#inc').on('click', function () {
  $('#app').rqMutate('count', function (n) { return n + 1; });
});

$('#dec').on('click', function () {
  $('#app').rqMutate('count', function (n) { return n - 1; });
});
Live demo
2

Toggle a boolean

js 
$('#app').rqState({ dark: false });

$('#toggle').on('click', function () {
  // Flip true ↔ false
  $('#app').rqMutate('dark', function (current) { return !current; });
});

3

Add to an array

js 
$('#app').rqState({ items: ['Apples', 'Bananas'] });

$('#add').on('click', function () {
  var text = $('#new-item').val().trim();
  if (!text) return;

  $('#app').rqMutate('items', function (list) {
    return list.concat(text); // return a new array
  });

  $('#new-item').val('');
});
Live demo
    Why rqMutate instead of rqSet? If you use .rqSet() to change an array, you have to first read it with .rqGet(), then modify the copy, then write it back. .rqMutate() does all that in one step — your function receives the current value automatically.
