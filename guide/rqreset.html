.rqReset()

Put state back to the values you started with. Pass a key to reset just that one value, or call with no argument to reset everything at once.

$(selector).rqReset() — reset all keys
$(selector).rqReset( key ) — reset one key

Parameters

Name Type Required Description
key string optional If provided, only that key is reset. If left out, every key returns to its original value.
Returns: the jQuery object (chainable)
1

Reset the whole form

js 
$('#app').rqState({ name: '', email: '', message: '' });

$('#reset-btn').on('click', function () {
  $('#app').rqReset(); // clears all three fields
});
Live demo — fill in the fields, then hit Reset
2

Reset a single key, leaving others alone

js 
$('#app').rqState({ score: 0, name: 'Player 1' });

$('#reset-score').on('click', function () {
  $('#app').rqReset('score'); // only score goes back to 0
                               // name stays as-is
});
Live demo — change both, then reset only the score
