.rqSet()

Change a state value and update the page automatically. This is how you make things happen — every time you call .rqSet(), any HTML element bound to that key updates instantly.

$(selector).rqSet( key, value )
$(selector).rqSet( { key: value, key2: value2, … } )

Parameters

Name Type Required Description
key string yes* The state key to update. Must have been declared in .rqState().
value any yes* The new value.
or object object yes* Pass an object to update multiple keys at once: .rqSet({ a: 1, b: 2 })
Returns: the jQuery object (chainable)
1

Set a single value

js 
$('#app').rqState({ status: 'idle' });

$('#ready-btn').on('click', function () {
  $('#app').rqSet('status', 'ready');
});

$('#busy-btn').on('click', function () {
  $('#app').rqSet('status', 'busy');
});

2

Set multiple values at once

js 
$('#app').rqState({ firstName: '', lastName: '', age: 0 });

$('#fill-btn').on('click', function () {
  // Update all three keys in one call
  $('#app').rqSet({
    firstName: 'Ada',
    lastName:  'Lovelace',
    age:       207
  });
});
Live demo — click "Fill in" to set all three fields at once

Tip: If you need to update a value based on what it already is (like adding 1 to a counter), use .rqMutate() instead — it gives you the current value to work with inside the function.
