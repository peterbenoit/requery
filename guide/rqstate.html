.rqState()

Attach data to an element and make that element reactive. Call this once on your container element to get started — everything else flows from here.

$(selector).rqState( initialData )
$(selector).rqState( initialData, options )

Parameters

Name Type Required Description
initialData object yes Your starting values. Any key you want to use must appear here.
options.persist string optional A unique name. When set, state is saved to localStorage and restored on the next page load. See Saving Data.
options.onChange function optional Called as onChange(key, newValue, oldValue) whenever any state key changes.
options.onInit function optional Called once after the initial render, with a snapshot of the full state as the argument.
options.debug boolean optional When true, logs every state change to the browser console.
options.actions object optional Named event handlers for data-rq-on-* attributes. See data-rq-on-*.
Returns: the jQuery object (chainable)
1

Basic counter

html 
<div id="app">
  <p>Count: <span data-rq-text="count"></span></p>
  <button id="inc">+1</button>
</div>
js 
$('#app').rqState({ count: 0 });

$('#inc').on('click', function () {
  $('#app').rqMutate('count', function (n) { return n + 1; });
});

Using onChange to react to any change

js 
$('#app').rqState({ name: 'world' }, {
  onChange: function (key, newVal, oldVal) {
    console.log(key + ' changed from ' + oldVal + ' to ' + newVal);
  }
});

Using onInit to run code after the first render

js 
$('#app').rqState({ score: 42 }, {
  onInit: function (state) {
    console.log('Ready! Starting score:', state.score);
  }
});
