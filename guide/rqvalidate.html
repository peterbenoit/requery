rq-validate

A form validation plugin for reQuery. Write a rule for each field — a function that returns an error message or null. Errors land in state as _errors so the rest of reQuery's binding system can display them.

Loading

html 
<!-- Load jQuery, then reQuery, then the plugin -->
<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>
<script src="https://cdn.jsdelivr.net/gh/peterbenoit/requery@main/dist/requery.umd.js"></script>
<script src="rq-validate.js"></script>

Methods added

$(selector).rqValidate( rules )
$(selector).rqValidate( rules, options )
$(selector).rqIsValid()
Parameter Type Description
rules object Keys match your state keys. Each value is a function that receives the current field value (and optionally the full state) and returns an error string, or null if valid.
options.validateOn string 'change' (default) — validate as the user types.
'blur' — validate when a field loses focus.
'submit' — validate on form submit; prevents the default submit if any field is invalid.
options.onValid function Called whenever all fields become error-free. Receives a snapshot of the full state.
options.onInvalid function Called whenever any field has an error. Receives the errors object and a snapshot of the full state.
rqValidate returns this (chainable).
rqIsValid returns a boolean — not chainable.

How errors work

After rqValidate runs, errors are stored in state under the key _errors as a plain object: { name: null, email: "Enter a valid email" }. A null value means the field passed. You read errors the same way you read any other state — via a watcher, rqGet('_errors'), or by watching individual error messages with a watcher.

1

Basic form validation

html 
<div id="form">
  <div>
    <input type="text" data-rq-val="name" placeholder="Your name" />
    <span class="error" id="name-error"></span>
  </div>
  <div>
    <input type="text" data-rq-val="email" placeholder="Email address" />
    <span class="error" id="email-error"></span>
  </div>
  <button id="submit">Submit</button>
</div>
js 
$('#form')
  .rqState({ name: '', email: '' })
  .rqValidate({
    name:  function (val) { return val.trim().length < 2 ? 'Name must be at least 2 characters' : null; },
    email: function (val) { return !val.includes('@') ? 'Enter a valid email address' : null; },
  });

// Show errors in the DOM using a watcher
$('#form').rqWatch('_errors', function (errors) {
  $('#name-error').text(errors.name || '');
  $('#email-error').text(errors.email || '');
});

$('#submit').on('click', function () {
  if ($('#form').rqIsValid()) {
    alert('Submitted! ' + JSON.stringify($('#form').rqGet()));
  }
});

Validate on blur (when the field loses focus)

Pass validateOn: 'blur' to only show errors after the user has finished typing and moved to the next field. Less noisy than validating on every keystroke.

js 
$('#form')
  .rqState({ username: '', password: '' })
  .rqValidate({
    username: function (val) { return val.length < 3 ? 'Username must be at least 3 characters' : null; },
    password: function (val) { return val.length < 8 ? 'Password must be at least 8 characters' : null; },
  }, { validateOn: 'blur' });

$('#form').rqWatch('_errors', function (errors) {
  $('#username-err').text(errors.username || '');
  $('#password-err').text(errors.password || '');
});
Live demo — errors appear after you leave each field
3

Cross-field validation

Each rule receives the full state as its second argument, so you can validate one field against another — like confirming a password matches.

js 
$('#form')
  .rqState({ password: '', confirm: '' })
  .rqValidate({
    password: function (val) { return val.length < 8 ? 'Password must be at least 8 characters' : null; },
    confirm:  function (val, state) { return val !== state.password ? 'Passwords do not match' : null; },
  });
