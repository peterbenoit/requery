.rqWatch()

Run a function every time a specific state key changes. Use this when you need to do something that a simple data-rq-text attribute can't do — like sending a request, playing a sound, or writing to a log.

$(selector).rqWatch( key, function(newValue, oldValue) { … } )

Parameters

Name Type Required Description
key string yes The state key to watch.
fn function yes Called as fn(newValue, oldValue) every time that key changes.
Returns: the jQuery object (chainable)
1

Show a message when a counter reaches a milestone

js 
$('#app').rqState({ count: 0 });

$('#app').rqWatch('count', function (newVal) {
  if (newVal >= 5) {
    $('#milestone').text('You reached 5! 🎉');
  } else {
    $('#milestone').text('');
  }
});
Live demo — reach 5 to trigger the watcher

2

Log every change with old and new values

js 
$('#app').rqState({ username: '' });

$('#app').rqWatch('username', function (newVal, oldVal) {
  console.log('Changed from "' + oldVal + '" to "' + newVal + '"');
});
Live demo — type to see the change log

Tip: The watcher runs after the DOM has already been updated with the new value. So if you need to do something based on the new value that's not just showing text, .rqWatch() is the right tool.
